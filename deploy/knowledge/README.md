# 知识库目录

把要给学员检索的 Markdown 资料放进这个目录（子目录随意），例如课程讲义、培训文档、FAQ。

- **生效方式**：扔文件进去即可。agent 每次新会话启动时自动检测变化并重建向量索引（约 8 秒，后台进行），不需要重启服务。
- **学员怎么用**：通话中直接问「文档里关于 XX 怎么说的」，助手会自动检索这里的资料回答。
- **今日待办工具**：如需 `query_today_tasks`（「我今天有什么待办」），在此目录放一个 `daily-tasks.md`，按日期标题分节（如 `## 2026-07-29`）。
- 宿主机目录路径可在 `.env` 里用 `KNOWLEDGE_HOST_DIR` 改成别处。
