对比定位：本 demo 是「编排框架 + realtime 一体模型」路线，与现有 voice-agent（浏览器直连百炼 WS，~250ms）对比。 多花 ~260ms 编排成本，换来工具调用 / 知识库 RAG / 多模型混编 / 电话 SIP 接入的一等公民能力。
前端交互：通话面板借鉴 FastRTC 的电话式 UX —— 大圆球随说话音量呼吸缩放、三层脉冲波纹、静音按钮；数据通道仍是 LiveKit WebRTC。
已知兼容处理：livekit 插件锁定 1.1.7（≥1.2 发 OpenAI GA 协议，百炼兼容端点仅支持 beta，会静默超时）； 百炼不回显 response.metadata，已打关联回退补丁。
玩法：点大圆球开始通话，授权麦克风后直接说话；助手说话时可以插话测试打断，🎙️ 按钮可静音。
